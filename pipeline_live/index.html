Run the pipeline yourself

This page is a demo of the finished project. You do not build anything here. You press a button, and watch the pipeline you will learn to build do one morning of work.

What is this, and why run it?

A grocery company needs one report every morning

  • Arden's manager asks: how many orders did we take yesterday, and how much money?
  • The orders live in the order system. A pipeline copies them into a warehouse and adds them up.
  • Each Run below is one morning of that pipeline. What you get is the report on the right.
  • The point: the report stays right, also when things go wrong. That is what the five milestones teach.

Try these four things, in order

Each one shows a problem the project solves

  1. On Tuesday an old day, Friday, changes. The page says why.
  2. Nothing may change.
  3. The pipeline should survive both. The report stays right.
  4. Now the pipeline should stop, on purpose. A normal Thursday run does not break anything: the bad row does.

All four done. You have seen what the project builds. Next: start milestone 1.
